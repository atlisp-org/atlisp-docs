#+title: 开发工具的安装
* winget
winget 需要win10 22H2 以上的系统。

一般系统可能没有winget源，只有msstore源。
当没有winget 源时，打开终端管理员（powershell 管理员）执行以下命令

#+begin_src shell
winget source reset  --force
#+end_src

* dotnet
安装.NET SDK
#+begin_src shell
winget install  Microsoft.DotNet.SDK.10  -s winget
#+end_src
* python
安装 Python 
#+begin_src shell
winget install  Python.Python.3.12
#+end_src

* @lisp python版的管理器
需要先安装 python 。(见上)
#+begin_src shell
  pip install atlisp
#+end_src
然后 执行 atlisp -h 查看相应的功能
#+begin_src shell
  atlisp -h
#+end_src

主要功能的：
    install             安装 atlisp 到CAD
    batch               批处理指定文件夹下的dwg
    find                在指定文件夹下的dwg中查找
    list                列出当前已安装的 @lisp 应用包
    pull                下载安装应用包到 CAD
    search              从网络搜索 @lisp 应用包

* 其它软件
可以使用 winget 的 search 功能搜索需要的软件，如 git , vscode等。然后 用
winget install ID 就可以安装这些软件了。

git代码管理
#+begin_src shell
  winget  search git 
  winget install  git.git
#+end_src
vscode 开发编辑器
#+begin_src shell
  winget search vscode
  winget install Microsoft.VisualStudioCode

#+end_src
CAD相关软件 
#+begin_src shell
  winget search CAD
  winget install ZWSOFT.ZWCAD.2026
#+end_src
