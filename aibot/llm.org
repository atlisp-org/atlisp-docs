* 本地部署大模型
分4步
- 安装Ollama
- 拉取模型
- 运行模型
- 交流
* 安装Ollama
windows 命令行(cmd)或powershell中运行
```
winget install ollama.ollama
```
这是用winget下载安装ollama.因为是从github下载的。有些网络可能太慢或根本不通。

可以从群文件中下载ollamasetup.exe手动安装

* 拉取模型

```
ollama pull deepseek-r1:1.5b
```
* 运行模型
```
ollama run deepseek-r1:1.5b
```
当加载完成后就可以在命令行与模型进行交流了。

* 更改模型路径
ollama默认模型存放位置为用户文件夹下的.ollama文件夹。
可以使用 mklink 建立目录链接到其它位置。
也可以设置变量 OLLAMA_MODELS 指定LLM的存放位置
